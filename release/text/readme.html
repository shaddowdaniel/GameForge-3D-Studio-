ATOM GameForge

Sobre

O GameForge 3D Studio é o editor 3D de jogos feitos na Angelica Engine (Perfect World e derivados). Ele abre os arquivos do cliente diretamente (pacotes .pck, modelos, terrenos e mapas) e reúne modelagem, pintura de texturas, rigging, animação, renderização e edição de vídeo em um só lugar.

Mais informações em atomgameforge.com.

Problemas

Se encontrar um problema, use Ajuda → Relatar um problema dentro do GameForge 3D Studio ou entre em contato pelo atomgameforge.com. Descreva os passos para reproduzir e, se possível, envie o arquivo .blend que mostra o problema.

Conteúdo do pacote

  • O aplicativo GameForge 3D Studio para Windows.
  • Complementos que ampliam as funções do Studio.
  • Este leia-me e os arquivos de licença.

Instalação

Use o instalador .msi, ou extraia o pacote .zip em qualquer pasta e abra GameForge3DStudio-launcher.exe.
